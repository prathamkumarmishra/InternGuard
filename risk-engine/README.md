# InternGuard C++17 Risk Engine

Reads one JSON document from standard input and writes one JSON document to standard output. It is a screening-signal engine, never a fraud classifier. The implementation demonstrates a Trie, hash maps, string matching, binary search, sorting, priority queue, stack, queue, and relationship graph BFS.

Build with `cmake -S . -B build && cmake --build build`, then run tests with `ctest --test-dir build`.
